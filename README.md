# AI News Digest

Daily email digest of AI news from RSS feeds (The Verge, TechCrunch, The Decoder, MIT Technology Review, Ars Technica, VentureBeat, Wired, The Information, Hacker News, Simon Willison).

- Runs every day at 06:00 (Brasília) via GitHub Actions.
- Top 3–5 highlights ranked by how many sources covered the story.
- Duplicate stories merged into one entry with links to every source.
- Remaining stories grouped by topic, one line each.
